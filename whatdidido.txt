July summary tl;dr - putting new components into Sb, Bc and Bo designs, one shared components library.

Ksenia also connected in to this library to help her visualise Cashier designs in Sb/Bc styles. Primary benefit is having one source of components for our main products (and yes, all styling can still be unique for each product, for example Sb has different font); more control over version history and publishing; more space for the components and variables. Sucky thing about the change of strategy is to now wait again for the devs to pick it up. https://www.figma.com/files/project/408714341

Thanks to Ksenia for being helpful and a sniper to spot these differences. We decided to adjust all the colors to match the current live products.

8 January
- Today, I worked on defining a token strategy for component design. I explored three approaches: creating separate tokens for each component, using a single global token collection, or having component-specific tokens that reference global ones. I decided on the third option as it balances consistency and flexibility. This approach ensures all components inherit shared values like sizes, border radii, and colors from global tokens, while still allowing individual components to override these values when needed.
